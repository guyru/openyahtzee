The development of Open Yahtzee 1.7 is almost complete and it should be

which will be incorporated in the upcoming version.

## 12 Dec. 2006
I released today a bug fix version for Open Yahtzee, Open Yahtzee 1.5.1 fixes several bugs found in the way the high score table was handled.
This release also contains ebuild for gentoo users.

## 18 Oct. 2006
I released today the first beta for Open Yahtzee 1.5. The biggest change
introduced in this version is the new high-score table, which is easy
customizable.

You can read the full announcement about this release in:
[https://sourceforge.net/forum/forum.php?forum_id=624679](https://sourceforge.net/forum/forum.php?forum_id=624679)
You can download this release via sourceforge.
[Click here to download](https://sourceforge.net/project/showfiles.php?group_id=175453&package_id=201410&release_id=456656)

## 10 Oct. 2006 I finished working on the basic functionality of the
highscore table. Everything is ready except the UI for dynamically
setting the table's length. You can try it out by checking out from the
CVS under module "OpenYahtzee" and tag "alpha_1-5".
